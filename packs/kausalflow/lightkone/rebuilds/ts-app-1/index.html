Lightkone

A research-paper library for people who read a lot of papers and want to own their data.

Open the app

Your files, your storage

The library is lightkone/library.json and a generated library.bib, in the storage you choose: this browser, an S3-compatible bucket (S3, R2, MinIO), or a private GitHub repository. There is no lightkone server and no account.

Collect

Paste arXiv ids, DOIs, links or BibTeX, import a .bib from Paperpile, Zotero, JabRef or Google Scholar, or drop PDFs. Free PDFs are fetched and filed the way Paperpile files them.

Find

A small query language: tag:, author:, year:2018-2021, in:Physics/QFT, has:pdf, is:starred, with accent-insensitive words, and search inside the PDFs you have read.

Read and cite

Read and highlight PDFs on a computer or a phone, offline too. Cite as \cite{key}, BibTeX, Markdown, APA or a journal style, and keep a folder's .bib in sync with your Overleaf project through GitHub.

Several devices, and your AI app

Every save merges, so two devices never overwrite each other. With a bucket or GitHub, an MCP address lets Claude search, read and tag your papers.

Lightkone builds to static files any static host can serve. Install it from your browser to use it as an app.
